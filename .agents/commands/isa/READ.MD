# ISA
This workflow is from product idea to a working app, driven by one `_ai/docs/ISA.md`. Use it for a whole product, not a one-off feature.

## Purpose
- Don't really use the `/goal-isa`, it's mostly for Openchamber `/craft-goal` specific feature

## FLOW
1. Define the product into one ISA using `.agents/commands/isa/product-isa.md`
2. Full autonomous software factory with `.agents/commands/isa/isa-factory.md`
3. Done

# Tools
- Product ISA skill: `.agents/skills/product-isa/SKILL.md`
- ISA Factory skill: `.agents/skills/isa-factory/factory/SKILL.md`
