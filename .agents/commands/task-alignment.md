Purpose: Confirm shared understanding before work begins.
When to use: Run this after agreeing on a task and before implementing or delegating it.

Using only the agreements and context already provided, populate the template below.

Do not execute, implement, delegate, edit files, or take any other action. Return only the completed template inside a Markdown code block. Do not add commentary before or after it, and wait for explicit approval before execution.

Based on our agreements fill out this template

```
* Problem Statement: [Describe the problem and why it matters.] 
* Goal: [Define the exact, measurable outcome.] * Boundaries: [State constraints, exclusions, and non-goals.] 
* Current State: [Describe how things work today.] 
* Ideal State: [Describe how things should work when complete.] * Verification: [Choose Lightweight, Balanced, or Thorough verification, and define success.]
```
