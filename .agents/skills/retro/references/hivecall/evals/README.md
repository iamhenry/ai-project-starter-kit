# Hivecall trace dataset

From the repository root, `python3 .agents/skills/retro/references/hivecall/scripts/build-dataset.py` fetches explicit hivecall invocations from archived threads only; unarchived (live) runs are never included. It appends a redacted run record once, then `runUpdate` records for new moments or changed worker reports; it never rewrites existing rows. Behaviors 4 and 6 come only from the event that launches a worker (a delegation start or `bb thread spawn`); completions and later reports are never start moments, and context ends before the launch. Every moment's `actualNextAction` stores its source `eventType` and item `status`; a B4/B6 start has `eventType: "item/started"` (a delegation start has `status: "pending"`). Behaviors 1–2 come only from completed structured edits to `ISA.html` or `checklist.html` that add a checked item or an explicit `ISC-n: PASS|FAIL|BLOCKED|park` verdict. A baseline with fewer than 10 moments for either behavior is reported as incomplete. Records keep the invocation week, loaded skill-copy category/content hash, repository commit nearest the invocation time, direct worker IDs/reports, and bounded moments. Raw logs are never stored; the file is capped at 25 MiB.

Use `python3 .agents/skills/retro/references/hivecall/scripts/count-moments.py` for the per-behavior count. Run `python3 .agents/skills/retro/references/hivecall/scripts/redact.py --scan .agents/skills/retro/references/hivecall/evals/dataset.jsonl` before committing or sending excerpts to a cloud model. For a no-network Clef request preview, run `python3 .agents/skills/retro/references/hivecall/scripts/digest.py --preview runs.json`.

Moments are tagged 1–7 using explicit per-item decisions, item-specific proof cues, long gaps with only pre-action context, actual delegation actions, watchdog-prefixed incoming alerts with their trigger retained, elapsed run duration, and aggregate token counts when logged. USD cost is recorded as unavailable because the provider log has no price data. Status tables and shell help are not item/delegation events. These are deterministic screening labels, not model judgments. Older `week` values support held-out evaluation. Run `python3 .agents/skills/retro/references/hivecall/evals/self-check.py` for the local parser/append regression checks; no network calls are made.
