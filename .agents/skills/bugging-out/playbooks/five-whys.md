# Five Whys

Goes deep. Fits when the failing spot is known but a fix there would only treat the symptom.

Follow the `five-whys` skill (`.agents/skills/5-whys/SKILL.md`).

Unlike the funnel, which tests many causes side by side, this follows one chain down: ask why, find evidence, ask the next why only if it narrows the cause.

Done when the fix targets a cause you can change within scope.
