# Hypothesis Funnel

Goes wide. Fits when there are several suspects and no clear lead.

1. List 5-7 possible causes across layers: input, state, logic, timing, config, dependency, environment.
2. Rank by evidence already in hand. Keep the top 1-2.
3. For each, find one check whose result would differ depending on which is true.
4. Run it. Mark each confirmed, ruled out, or still a guess.
5. If all are ruled out, relist using what you just learned.

Stalls when every new list looks like the last one. Switch to tracing or comparing.
